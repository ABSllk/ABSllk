#### About

I am a developer and researcher based in China. I like peeling back abstractions rather than stopping at a working API call—understanding how things are built, how they break, and why they behave the way they do.

My technical path has unfolded across three stages, plus one side interest:

- **Algorithms (Where it began)** — Started with competitive programming (OI), which shaped how I think about complexity, data structures, and solving problems from first principles.
- **Cybersecurity** — Moved into offensive and defensive security, focusing on vulnerability analysis, penetration testing, and real-world attack surfaces.
- **AI × Security → AI Security (Current focus)** — First brought LLMs and agents into security workflows (pentesting, automated CVE/PoC analysis, and cyber deception), then stepped away from PyTorch to rebuild an LLM stack from scratch (`ABS-GPT`) to understand the mechanics underneath. Now I am increasingly focused on **AI Security**—studying model behavior, post-training/alignment dynamics, and the security boundaries of AI systems and agents.
- **Quantitative Trading (Side interest)** — Outside security and AI systems, I tinker with quantitative trading infrastructure, strategy frameworks, and execution interfaces.

#### Selected Projects

- **[Hexestra](https://github.com/ABSllk/Hexestra)** (`TypeScript`)  
  An AI-native penetration testing workbench where human operators and AI agents collaborate on a shared operational surface—browser, terminals, managed shells, HTTP traffic, asset graphs, and structured task plans.

- **[ABS-GPT](https://github.com/ABSllk/ABS-GPT)** (`Python`)  
  A from-scratch LLM learning project written in NumPy and CuPy without PyTorch—covering custom autograd, Transformer architecture (GQA, MoE, MTP, Muon), and a unified suite of post-training algorithms (SFT, GRPO, DAPO, GSPO, DPO, IPO, SimPO, ORPO).

- **[CVE_Montior_with_LLM](https://github.com/ABSllk/CVE_Montior_with_LLM)** (`Python`)  
  Collects newly disclosed CVEs and their PoCs, uses LLMs to break down exploitation steps into structured SOPs, and generates honeypot scripts to simulate the vulnerabilities.

- **[HoneyLLM](https://github.com/ABSllk/HoneyLLM)** (`Python`)  
  Experiments in LLM-powered cyber deception and adaptive honeypot design.
